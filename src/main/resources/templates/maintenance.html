Maintenance

Export a bundle

A zip of cached files with their checksums, to import on another machine. To take one project's dependencies along, build it (with --refresh-dependencies for Gradle), then export what was used in that time.

Import a bundle

Files the cache already has are kept; anything that does not match the bundle's checksums is rejected.

Prefetch

Download ahead of time, for example before going offline. One group:artifact:version or repository path per line, or paste a Gradle verification-metadata.xml.

Purge

Delete cached files below a path, unused for a number of days, or both.

Size limit

No size limit. Set localrepo.max-size (e.g. 20GB) to delete the least recently used files automatically.
